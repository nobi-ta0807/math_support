# MathCards Ver. 1.0（依存ライブラリなしの実動版）

## 起動

`index.html` をブラウザで開くと基本機能を利用できます。PWA（オフラインキャッシュ／ホーム画面追加）の動作には HTTP(S) での配信が必要です。

ローカルで動作確認する場合はフォルダ内で `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開いてください。GitHub Pagesには **MathCards_app 内のファイルをそのまま公開ディレクトリへ配置**してください。相対パス指定なのでリポジトリのサブパスでも利用できます。

## 対応済み

- ホーム・解法一覧・カード詳細・カード編集・復習・設定、PCとスマホのレスポンシブUI
- カードの作成／編集／複製／ソフト削除／復元／完全削除、IndexedDBへの保存と約1秒後の自動保存
- 3つのリッチテキスト入力欄、太字／斜体／下線／見出し／リスト／Undo／Redo
- LaTeX数式テンプレート挿入・編集。ネット接続時にはMathLiveの視覚的入力とKaTeXの組版表示を利用（CDN読み込みに成功した場合）
- 画像選択・貼り付け・サイズ抑制、リッチテキスト内表示
- 階層フォルダ・移動・名前変更・削除、タグ、全文検索、難易度、並べ替え
- カード内リンク・カードIDでの参照・複製
- 自由／自動／苦手復習、評価履歴と復習日程、進捗・習得率
- JSONバックアップ・読み込み（追加／置換）、ライト／ダーク／システムテーマ
- PWA manifestとService Workerキャッシュ（HTTP(S)配信時）

## 指示書と比べた制約・未対応

この版は外部パッケージに接続できない実行環境で生成しており、推奨構成のReact / TypeScript / TipTap / MathLive / KaTeX / Dexieは同梱していません。**数式入力・表示のライブラリはCDN読み込み方式です。** 初回オフライン環境やCDNへのアクセスが失敗した場合は、LaTeX文字列入力・表示にフォールバックします。完全オフライン対応にはMathLive・KaTeXのローカル同梱が必要です。

画像はIndexedDBの`assets`にも格納しますが、本文にもData URLで埋め込まれます。画像を別アセットIDのみで管理する設計にはまだなっていません。画像の任意サイズ変更、ドラッグ&ドロップによる画像挿入、全操作の取り消し、インポート処理全体のトランザクション化、ブラウザ間同期、数式の完全な視覚編集は今後の改善点です。下書き保存ではタイトル空欄も許可しています。

このため、元指示書の受け入れテストを**すべて満たす完成版ではありません**。バックアップを定期的にエクスポートしてください。

## 今回の更新（数式機能）

- KaTeXによる数式組版を追加（読み込み成功時）。
- MathLiveによる分数・指数・行列などの視覚的な編集欄を追加（読み込み成功時）。
- 保存データは引き続きLaTeX文字列のため、旧版カードとの互換性を維持。
- CDNが使えない場合も従来の数式入力で操作可能。

**注意**：外部CDNを使うため、現段階では数式ライブラリまで含めた完全オフライン対応ではありません。

## Ver.1.2 数式編集の改善
- カード編集画面に常時表示の数式キーボード（基本・関数・記号）を追加しました。sin/cos/tan、log/ln、e、π、分数、累乗などを選択できます。
- 数式をクリックすると、MathLive が利用可能な場合は分数や指数を見たまま直接編集できます。変更は既存の自動保存に反映されます。
- ツールバーの「数式」「独立数式」は編集欄内に数式を直接挿入します。
- **制約**: MathLive/KaTeX は CDN 読み込みのため初回利用には通信が必要です。ブラウザ実操作の自動テストは未実施です。


## Ver. 1.3.0 更新
- サイドバーおよびスマホ画面下部にバージョン番号を表示。
- Service Worker のキャッシュ名を更新し、HTML/CSS/JS はネットワーク優先で更新確認。
- MathLive は CDN 依存です。ネットワーク制限やCDN読み込み失敗時は視覚的編集を利用できません。
- 既存の IndexedDB は削除しません。
